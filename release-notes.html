Release notes

What changed in each version.

Version 0.9.4October 7, 2026

New

  • Firmware V2.0. The hub now reaches inputs 65 to 96, the extra groups, auxes and matrices, and the UFX sends and returns. Each board has a Firmware setting: choose "Before V2.0" for a console on older firmware.
  • Pages in Show view. Build your own tabs of channels in any order, like a custom layer on the console. Click Pages… at the top of the surface.
  • Named. A button in Board Targets and in Show view that hides every channel nobody has named on the console.
  • The search field in Board Targets has a clear button.
  • A Copy button in the Monitor puts every line on the clipboard.
  • Settings > Inputs links to where AbletonOSC can be downloaded.
  • Experimental: a board can read which inputs are muted as it connects, so those mutes are known from the start. It is off unless you turn it on, it only reads, and it should be tried at a quiet console first. See the manual.

Changed

  • A mute the console has not reported yet now reads "MUTE ?" with a dashed edge, so it cannot be taken for a mute that is known to be off.
  • The hub no longer sends a fader the same level twice in a row.
  • The User Manual and FAQ have a contents list down the side, sharper screenshots that open large when clicked, and new sections on firmware, pages and mutes.

Fixed

  • Channel names from the console no longer carry invisible padding, which could stop a name being matched.
  • The hub no longer warns that the two halves of the LR main share a name.

The companion app should be updated alongside this version, so that it knows the new kinds of channel.

Version 0.9.3October 6, 2026

Fixed

  • The Use button beside a trigger with a long name is no longer squeezed. The name is shortened instead.
  • The help under Base MIDI channel in Settings is no longer cut off.

The companion app's next version fixes the Direct control line on the iPhone's Status screen, which was cut off.

Version 0.9.2October 6, 2026

Changed

  • The hub now checks for updates even while armed. A hub that is always armed used to miss them altogether.
  • An update found while armed opens no window. An Update marker shows at the top of the window, in the menu bar panel and in Settings, and waits for a click.
  • Installing still asks before it quits an armed hub.

Version 0.9.1October 6, 2026

New

  • Help menu: the User Manual, FAQ and these Release Notes.

This version is mainly here to prove that updating works.

Version 0.9October 6, 2026

The first version that can update itself.

  • Check for Updates in the Avantis Hub menu, and an Updates tab in Settings. The hub checks once a day, never installs without being asked, and never checks while armed.
  • The companion app now runs on iPad, with the quick buttons and the hub's status side by side.
  • A clip in Ableton Live's Session view can press the quick button with the same name.
  • Settings > Devices lists paired devices, and each one's settings open with a click.
