Version 0.9October 6, 2026

The first version that can update itself.

  • Check for Updates in the Avantis Hub menu, and an Updates tab in Settings. The hub checks once a day, never installs without being asked, and never checks while armed.
  • The companion app now runs on iPad, with the quick buttons and the hub's status side by side.
  • A clip in Ableton Live's Session view can press the quick button with the same name.
  • Settings > Devices lists paired devices, and each one's settings open with a click.
